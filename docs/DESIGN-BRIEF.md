# Codrithm Website Concept — Design Brief

## Brand expression

The experience should feel purposeful, modern, welcoming, and ambitious—not corporate or exclusionary. It should make new developers feel that technology is a place where they belong and can contribute.

## Core message

**Where Coders Make History.**

Supporting message: Codrithm helps emerging developers gain practical skills, peer mentorship, and collaborative experience.

## Visual direction

- **Mood:** dark, high-contrast technology environment with human warmth.
- **Shape language:** soft rounded cards, subtle borders, generous spacing, clear hierarchy.
- **Imagery:** abstract technological light, community/project moments, and editorial imagery that supports real stories.
- **Motion:** restrained and purposeful—introduce hierarchy or feedback, never visual noise.

## Brand color system

| Token | Hex | Role |
| --- | --- | --- |
| Codrithm Blue | `#0066FF` | Primary button fill, primary action, focus/highlight |
| Codrithm Green | `#87FFBC` | Supporting accent, positive status, subtle emphasis |
| Background | `#030A18` | Main dark canvas |
| Foreground | `#F7FBFF` | Primary text |

All visible action buttons should use a solid Codrithm Blue fill with white text/icons. Use green for accents and signals rather than as the primary button fill.

## Typography

- **Display:** Plus Jakarta Sans for headings; confident, concise, and spacious.
- **Body:** Manrope for readable supporting copy.
- **Voice:** clear, optimistic, direct, community-led. Avoid generic tech jargon and unsupported claims.

## Layout principles

1. Use one strong message per section.
2. Keep primary actions unmistakable through solid blue treatment.
3. Pair claims with evidence: numbers, examples, testimonials, or projects.
4. Use mobile-first spacing and comfortable tap targets.
5. Keep dense dashboard visuals illustrative; do not imply live data without a real source.

## Accessibility requirements

- Maintain readable contrast for text and controls.
- Never communicate meaning by color alone.
- Support keyboard navigation and visible focus.
- Provide accessible names for icon-only controls.
- Respect reduced-motion preferences; avoid auto-playing or continuous nonessential movement.
- Use descriptive alternative text for meaningful imagery; decorative imagery should be ignored by screen readers.

## Content direction

Replace placeholder-style material with verified Codrithm facts, authentic member stories, real event/project links, and approved organization contact details before launch. Any community figures must have a source and review owner.
